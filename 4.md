# Compare 1G, 2G, 3G, 4G, and 5G wireless systems

The transition from first-generation (1G) to fifth-generation (5G) mobile systems represents a shift from basic analog voice transmission to ultra-fast, multi-service digital network architectures. 

---

### **Key Evolution Highlights**

*   **1G (First Generation):** Deployed initially in Tokyo in 1979, 1G was an **analog system** designed purely for voice calls. Because it used basic Frequency Modulation (FM) and analog switching, calls were highly vulnerable to interception via simple FM demodulators, voice quality was poor, and roaming between networks was impossible.
*   **2G (Second Generation):** This marked the transition to **digital switching and transmission**, introducing the Global System for Mobile Communication (GSM) and Qualcomm's Code Division Multiple Access (CDMA). It introduced text messaging (SMS), basic email, encrypted voice calls, and roaming. Upgrades like GPRS (2.5G) and EDGE (2.75G) began offering packet-based data services.
*   **3G (Third Generation):** Based on UMTS, 3G boosted data rates to support **video calling, mobile web browsing, GPS tracking, and early TV streaming**, which triggered the global smartphone boom. Data rates were later improved to 2 Mbps using 3.5G/3.75G technologies like HSDPA and HSUPA, which eventually laid the groundwork for LTE.
*   **4G (Fourth Generation):** Offering speeds up to 1 Gbps, 4G introduced an all-IP packet architecture using **LTE and LTE-Advanced**. It enabled simultaneous transmission of voice and data by routing voice calls as IP packets over **VoLTE**, while lowering latency down to ~30–50 ms to enable high-definition mobile streaming and gaming.
*   **5G (Fifth Generation):** Operating on both Sub-6 GHz and high-frequency **millimeter-wave (mmWave)** bands, 5G delivers up to 10 Gbps with sub-millisecond latency. It supports standalone and non-standalone deployments and utilizes advanced features like **small cells, beamforming, and network slicing** to handle dense internet of things (IoT) devices, virtual reality, and mission-critical applications.
